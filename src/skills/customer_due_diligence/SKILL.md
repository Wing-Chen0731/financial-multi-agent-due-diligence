# 企业客户授信尽调

## 适用场景

用户要求对企业客户做尽调、授信材料整理、还款能力分析或风险报告时使用。

## 执行规则

1. 先识别客户名称，再调用客户查询工具。
2. 只使用工具返回的客户事实，不得补写不存在的收入、负债、评级或担保信息。
3. 需要财务指标时，必须使用用户提供的数据调用财务计算工具，并标明数据来源和时点。
4. 输出风险提示、缺失材料和下一步核查动作，不输出“建议批准”或“建议拒绝”。
5. 该 Skill 默认要求人工复核。

## 输出结构

- 已知事实
- 风险提示
- 缺失材料
- 建议核查动作
- 数据来源
