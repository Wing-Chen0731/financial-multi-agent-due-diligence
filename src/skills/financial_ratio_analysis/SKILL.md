# 财务指标分析

## 适用场景

用户提供收入、利润、负债等数字，并要求计算利润率、债务收入比或其他基础指标时使用。

## 执行规则

1. 明确单位、币种、期间和数据来源。
2. 缺少分母、分子或期间信息时先标记数据不足。
3. 展示公式和计算结果，保留必要的小数位。
4. 指标只用于辅助分析，不代表评级、授信、投资或合规结论。
5. 发现异常值时提示复核，不擅自修正用户数据。

## 输出结构

- 输入数据
- 计算公式
- 计算结果
- 口径限制
- 后续核查建议
